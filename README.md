## About Me

I'm a software developer with a multidisciplinary engineering background
in **C#/.NET, electronics, embedded systems, and robotics**.

For around four years, I have been developing and improving Windows
applications for specialized electrochemical instruments. My work brings
together desktop software, USB communication, ARM STM32-based devices,
measurement workflows, and real-time data visualization.

I enjoy working across disciplines: understanding how a device works,
designing the software that communicates with it, and turning complex
engineering requirements into reliable tools.
